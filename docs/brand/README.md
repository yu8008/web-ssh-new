# WebSSH Gateway · Open Gate

主标志以开放的 **G** 形轮廓表达 Gateway，内部 **`>`** 表达终端命令。两条路径、统一圆端与圆角，保留充足负空间。采用 SVG 原生几何绘制，无位图描摹、滤镜或渐变；单色印刷与深浅色界面均可使用。

主页面使用 CSS mask 配合现有主题强调色：深色界面 `#409dff`，浅色界面 `#315bc7`。主题切换即时生效。标签栏依据浏览器系统配色偏好切换颜色，独立于网页内主题；图标链接带版本参数，减少旧图标缓存干扰。品牌文字保留为可访问的真实文本，操作图标继续统一使用 Lucide。

保持外侧至少 12 个坐标单位的留白，不增加阴影、发光或额外边框，不拉伸。主标志建议显示尺寸至少 32 px；更小场景使用标签栏专用版。生产页面不加载候选方案或展示页。

## 设计探索

1. **Open Gate**：线条几何与字母结合，语义直接且小尺寸辨识好，选作产品标志。
2. **Fold**：纯几何折叠，双向通道，视觉重量更强。
3. **Pulse**：点阵命令符，强调数字传输，适合动效。
4. **Stream**：连续线条系统，强调持续同步，适合较大应用。
5. **Orbit**：几何圆环与节点结合，强调跨设备连接。
6. **Relay**：两端节点、连接通路与终端符号结合。

流程参考 [op7418/logo-generator-skill](https://github.com/op7418/logo-generator-skill) 的设计规范及展示模板的方案网格、悬停比较结构；具体图形与页面为本项目重新绘制和实现。展示完全使用本地 SVG、CSS 和字体，不需要 Gemini 密钥或图片服务。PNG 由浏览器对同一 SVG 渲染导出。
